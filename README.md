# 🎮 Игра «Виселица» (консольная версия)

## 📌 Описание

Консольная реализация классической игры «Виселица».
Игроку нужно угадать загаданное слово, вводя буквы.
За каждую ошибку добавляется часть виселицы.

## 🚀 Возможности

* Выбор уровня сложности:

    * Легкий — 8 попыток
    * Средний — 6 попыток
    * Сложный — 4 попытки
* Отображение прогресса слова (`*о*о`)
* Отображение неверных букв
* ASCII-графика виселицы
* Обработка повторных вводов
* Проверка корректности ввода

## 🧠 Правила игры

Игрок вводит буквы, пытаясь угадать слово.

* Если буква есть в слове — она открывается
* Если буквы нет — добавляется часть виселицы
* Победа — слово полностью угадано
* Поражение — превышено количество ошибок

Подробнее: https://ru.wikipedia.org/wiki/Виселица_(игра)

## 🛠️ Технологии

* Java 17+
* JUnit 5 (тесты)

## 📂 Структура проекта

* `hangman.game` — логика игры
* `hangman.ui` — пользовательский интерфейс
* `hangman.service` — работа со словами (WordService)

## ⚙️ Особенности реализации
- Используется enum для уровней сложности
- Логика отделена от UI
- Используется Maven для сборки проекта
- Применяются unit-тесты (JUnit 5)

## ▶️ Запуск

1. Клонировать репозиторий
2. Открыть в IntelliJ IDEA
3. Запустить класс `Main`
